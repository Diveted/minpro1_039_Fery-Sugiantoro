# Sistem Pengelolaan Koleksi Game

Sistem Pengelolaan Koleksi Game merupakan program Python sederhana
yang digunakan untuk mengelola data koleksi game.

Program ini menggunakan list sebagai tempat penyimpanan data sementara.
Program dijalankan menggunakan menu berulang dengan perulangan while
sampai pengguna memilih menu keluar.

Data yang dikelola dalam program ini meliputi:

- Nama game
- Genre game
- Platform game
- Status game

Status game terdiri dari:

1. Belum dimainkan
2. Sedang dimainkan
3. Sudah tamat

## Fitur Program

Program ini memiliki beberapa fitur, yaitu:

1. *Tambah Data Game*  
   Digunakan untuk menambahkan data game baru ke dalam list.

2. *Tampilkan Data Game*  
   Digunakan untuk menampilkan seluruh data game yang tersimpan.

3. *Ubah Data Game*  
   Digunakan untuk mengubah data game yang sudah tersimpan.

4. *Hapus Data Game*  
   Digunakan untuk menghapus data game berdasarkan nomor data.

5. *Keluar*  
   Digunakan untuk mengakhiri program.

## Konsep Python yang Digunakan

Konsep Python yang digunakan dalam program ini adalah:

- List
- Nested list
- Perulangan while
- Perulangan for
- Percabangan if, elif, dan else
- Input dan output
- append() untuk menambahkan data
- pop() untuk menghapus data
- len() untuk menghitung jumlah data
- isdigit() untuk memeriksa input angka
- lower() untuk mengubah huruf menjadi huruf kecil
